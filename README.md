# A config for Hyprland + Noctalia

This is my config for a Hyprland + Noctalia setup.

It is very tailored to my personal needs, so if you want to use it, you probably need to make some changes:
- some settings are only applied if the hostname matches (as I use this config for multiple devices)
- The Numpad is used for shortcuts

# Keybinds

- `SUPER + <number>`: switch to workspace \<number\>
- `SUPER + SHIFT + <number>`: move focused window to workspace \<number\>
- `SUPER + CTRL + <number>`: move focused window to workspace without following \<number\>

- `SUPER + S`: switch to special workspace
- `SUPER + SHIFT + S`: move focused window to special workspace
- `SUPER + CTRL + S`: move focused window to special workspace without following

- `SUPER + Q`: close focused window
- `SUPER + D`: toggle maximize for focused window
- `SUPER + F`: toggle fullscreen for focused window

- `KP_Delete (Numpad ,)`: Open NixOS Search
- `KP_Insert (Numpad 0)`: Open NixOS Config (`code ~/nixos-config`)
- `KP_Home (Numpad 7)` or AI Key: Swap system theme
- `KP_UP (Numpad 8)`: Swap workspaces between monitors (select the workspaces by tapping CTRL on each monitor)
- `KP_Prior (Numpad 9)`: Open next empty workspace (on all monitors)
- `SHIFT + KP_Prior (Numpad 9)`: Create new empty workspace by shifting all following one to the right

- `SUPER + E`: Dolphin
- `SUPER + B`: Firefox
- `SUPER + C`: VS Code
- `SUPER + T`: Vesktop (Discord)
- `SUPER + O`: Obsidian
- `SUPER + Escape`: System Monitor
- `SUPER + Return`: kitty

- `SUPER + '+'`: Zoom in
- `SUPER + '-'`: Zoom out

- `Print`: screenshot
- Default Keys like Volume Up, Wolumen Down, etc.
